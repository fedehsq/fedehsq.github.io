Touch Protector - FOREGROUND_SERVICE_SPECIAL_USE

This screen recording shows what the foreground service does while it runs, on a Pixel 10 Pro (Android 17):

  1. The user turns the touch lock on from the app.
  2. The lock is a full-screen overlay that absorbs touches, so the screen stops responding. The service keeps that overlay alive: it is the work the user asked for, and it must last until the user ends it.
  3. The ongoing notification posted by the foreground service is visible in the notification shade. It states that the lock is active and carries the Unlock button, one of the ways out of the lock.
  4. The user unlocks with the on-screen gesture; the overlay disappears and the service stops immediately.

The quick settings area is blurred because it showed the network name and personal device names. The app itself uses no network, no location, no camera and no microphone, and the lock is never restored automatically after a reboot.
